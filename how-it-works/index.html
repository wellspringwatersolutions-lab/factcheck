How it works

FactCheck splits a passage into claims, looks up sources, and returns a verdict for each claim. There is no overall score. A verdict is not proof.

  1. Paste an answer

    Paste an AI answer or a claim on the home page, or send the same text to the API or MCP plug-in.

  2. Split it into claims

    The checker breaks the passage into individual claims so each one can be checked on its own.

  3. Check facts against sources

    For checkable facts, it looks up evidence and quotes the passage a verdict rests on. A claim is marked supported only when a quoted source or a tool result backs it.

  4. Report what fact-checkers say

    For opinions, it reports what mainstream fact-checkers say. It does not label an opinion true or false.

  5. Read the verdict and the strength of support

    Each claim gets a verdict and a strength score from the evidence. The verdicts, from strongest support to least, are: supported, hypothesis (supported by evidence), opinion, conflicting, and unverified.
